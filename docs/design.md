# Design notes

The popup opens directly on three understated text tabs with a blue underline on the active page. There is no brand header or access-status banner. Search sits in one quiet field, followed by plain source/status filters. Each session fits on one 36-pixel row: a checkbox, an ellipsized thread title, a small source label, a bright, fixed-width status badge. The entire remaining row opens the thread, with copying as the fallback for agents without a direct link. Status badges pair a saturated dot with short text: Running in green, Needs input in orange, Done in blue, Error in red, Idle in gray and Unknown in purple. Color is never the only signal. Hover text keeps the full prompt, agent name and status available. Only the checkbox toggles monitoring. The row action is a separate button, with no Open button or title label attached to the checkbox. App opening goes through the local companion so no browser navigation or empty handoff tab occurs. Status tooltips show uncertainty causes and the last confirmed observation. Threads, Websites and Settings stay at the top. The thread view has text search, source and status filters, followed by a bounded scrolling list. Monitored threads stay in a separate pinned list above the filtered results, with their own bounded scrolling area. Available threads sort by last activity. Rows update in place to preserve focus, scroll and action feedback. The popup remembers its active page and both thread-list scroll positions. Websites use an add field and compact hostname rows with remove buttons; additions and removals save immediately.

Palette: mist #f5f7fc, ink #18213c, blue #264ab9, muted #56617b, rule #dce2ef, running #246d50. System sans keeps the extension small and follows the operating system. All content is left aligned. The blocking screen contains one heading followed by the affected sessions. A standalone reason appears only when there are no affected session rows. There is no repeated explanation, brand label or unlock hint. No animation or remote fonts.

The initial design review removed dashboard cards and counters. They did not help select a session or return to one. Borders separate selectable rows; color is reserved for the active tab and thread status. Both the document and body have matching 400 × 540 pixel dimensions so switching pages or changing selection cannot resize Firefox’s popup. The thread lists share a reserved scrollbar gutter so their checkbox, source and status columns align. Rows keep their DOM nodes when moved between the lists. The popup has shrinking title columns and vertical-only list scrolling.

When running work stops, a small white notice appears in the top-right of the current site. A blue circular counter shows 3, 2, 1, with the affected thread and a short explanation. It does not capture keyboard focus or pointer input. A full-page overlay covers the existing document at the deadline; resuming work removes the notice or overlay. The document stays mounted, preserving drafts and scroll position. Playing audio and video pause under the cover and resume from the same position when access returns. The site body is inert while the overlay is visible; the overlay lives in an isolated shadow root outside it. New restricted visits still use the standalone attention page.

Source, thread status and last activity use three matching dropdowns on one row. Last activity offers recent-time presets or a custom oldest/newest range in local time. The date fields appear below the dropdown row only when Custom range is selected. Filters persist across popup openings and do not alter monitoring selections. All status badges occupy the same 90-pixel width, including Needs input and Unknown.

Settings has one countdown field in seconds. Valid changes save immediately, with a small inline confirmation that clears after two seconds. The default is 3, and 0 disables the delay. Connection details live here rather than below every thread list. The Dark mode switch saves immediately and uses slate backgrounds, light text and bright status colors throughout the popup, countdown and attention screen. Both themes use the same layout. All three pages retain the same dimensions.

Any running agent is a compact settings switch. When on, a small label identifies the active policy on Threads, selected rows are labeled Saved selection. The list uses muted text and gray status badges, and selection checkboxes are disabled. Row actions remain available. Access follows any fresh running observation across all detected sources. The last running thread stopping gets the configured countdown; a missing or stale observation blocks immediately. Selected-thread choices are preserved when switching modes.
